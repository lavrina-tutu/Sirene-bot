# dev-workflow

Единый файловый маршрут для изменений Hermes и USERTOOLS. Норматив — Б55 master-ТЗ DevWorkflow; `extract.md` — только индекс и проигрывает master при расхождении.

Начните с `SKILL.md`, затем используйте `references/canon.md` для имён/G6 и `references/context.md` для межфазового пакета. Роли, модели и backend задаёт YAML `tools.dev_workflow`.

`hermes-feature` и `tz-workflow` сохраняют предметные инструкции, но не имеют собственной очереди, role launch или оркестрации.
