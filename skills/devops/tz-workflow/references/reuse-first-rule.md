# Reuse-first rule (Саша, 21.08.2026)
1. Решение задачи в первую очередь опирается на существующие приложения и сущности экосистемы: USERTOOLS-инструменты, external API/приложения (`applications` в EcosystemManifest.json), реестры (Registries/*.json), сущности vault (Entities/*).
2. Новые приложения/сущности предлагать ТОЛЬКО если существующие реально не решают задачу.
3. Любое предложение НОВЫХ сущностей (ТЗ / план / багфикс / доработка, любой уровень) — сначала на согласование Саше. Самостоятельно не внедрять.
