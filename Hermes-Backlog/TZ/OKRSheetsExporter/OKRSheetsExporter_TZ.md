# ТЗ: OKRSheetsExporter v0.1.0

**Дата:** 2026-08-06
**Автор:** Архитектор (на основе бриф-сессии OKRTool 06.08.2026)
**Статус:** Драфт

---

## 1. Философия

### Что делает OKRSheetsExporter

- Ручная команда: «экспортируй OKR за <период> в Sheets»
- **Читает:** per-task MD из `Projects/okr-tool/<period>/` (Правило №0 — никогда не ходит в Jira напрямую)
- **Строит:** сводную таблицу: Objective, KR, %, уверенность, риски, что сделано
- **Пишет:** push в Google Sheets через скилл `google-workspace`
- Никогда не часть основного чекин-флоу (отдельный мини-инструмент)

### Чего НЕ делает

- Не ходит в Jira (данные только из per-task MD)
- Не пишет в Jira
- Не запускается автоматически (только ручная команда)

---

## 2. Флоу

```
1. Пользователь → TG: «экспортируй OKR за Q3 2026 в Sheets»

2. OKRSheetsExporter:
   a. Читает все per-task MD из Projects/okr-tool/Q3 2026/
   b. Строит сводную таблицу:
      - Objective (группировка)
      - KR (ключ, название, ссылка)
      - % выполнения
      - Уверенность
      - Риски
      - Что сделано
   c. Создаёт Google Sheet через google-workspace
   d. Записывает таблицу
   e. Верифицирует через sheets get
   f. Возвращает ссылку на Sheet

3. Пользователь получает ссылку
```

## 3. Зависимости

| Инструмент | Роль |
|---|---|
| **OKRTool** | Источник данных (per-task MD) |
| **google-workspace** (скилл) | Создание и запись Google Sheets |

### Нюансы Google Sheets (из `tutu-jira-okr` SKILL.md)

- `sheets create` даёт локализованное имя листа (`Лист1`, не `Sheet1`) → использовать диапазон БЕЗ префикса листа (`A1:G8`)
- Интерпретатор Python указывать явным путём (не через venv)
- После `update` → `sheets get` для верификации

---

## 4. Формат сводной таблицы

| Колонка | Источник |
|---|---|
| Objective | frontmatter.parent_contains → summary |
| KR | frontmatter.key + frontmatter.type |
| Название | frontmatter.key → ссылка на Jira |
| % выполнения | per-task MD тело, секция чекина |
| Уверенность | per-task MD, поле confidence |
| Риски | per-task MD, поле risk |
| Что сделано | per-task MD, поле what_done |
