# Рецепт: поиск ссылки/ключа (JIRA и др.) в Loop по каналу или автору

Задача: «найди в Loop ссылку на задачу JIRA по разработке X», «ищи в канале Y (включая
подканалы) или от автора A/B». Проверено на живых запросах 15.09.2026.

## Ключевые факты API

1. **`GET /api/v4/teams/{team}/posts/search` НЕ существует в Loop.**
   Возвращает: `{"id":"api.context.404.app_error","message":"could not find the page"}`
   Любой terms-запрос вернёт 404. Полнотекстового поиска по API в Loop НЕТ.
   → Не трать время; обходи каналы и фильтруй клиентски.

2. **Пагинация постов:** `GET /channels/{cid}/posts?per_page=200&before=<pid>` — иди
   по `order[-1]` (последний pid) пока `order` не пуст. `since` нужен только когда
   важна свежесть; для полной истории используй `before`.

3. **Подканалы:** у канала есть `parent_id`. Чтобы найти сабканалы канала X:
   перечисли все каналы команды (`/api/v4/teams/{team}/channels?per_page=200&page=N`)
   и отфильтруй `c.get("parent_id")==X_id`. У связанных каналов (например
   `ai-analitik-internal`) могут быть свои сабканалы — искать рекурсивно.

4. **Нельзя перечислить каналы другого пользователя:**
   `GET /api/v4/users/{uid}/channels?team_id=...` для чужого uid возвращает `[]`
   (нет прав на кросс-юзер членства). → Чтобы найти посты автора (даже его DM),
   придётся фильтровать `user_id` в постах доступных каналов, либо найти эти
   каналы другим способом (Саша — member).

5. **Резолв ФИО → user_id:** `GET /api/v4/users/autocomplete?name=<подстрока>`.
   Возвращает `users` + `out_of_channel`. Пример: Галашов Владислав = username
   `galashov`, Жиров Александр = `zhirov`. id бери из ответа.

## Регулярки для фильтра кандидатов JIRA

```python
jira_url = re.compile(r"hq\.tutu\.ru/browse/[\w-]+", re.I)                        # ссылка
jira_key = re.compile(r"\b((?:ANL|ADD|DEV|OKRS|PLAN|PLATFORM|DATA|HF)-?\d{2,7})\b")  # ключ
word     = re.compile(r"разработк|продукт|продакт|агент", re.I)                   # сужение по теме
```

**Всегда сужай по слову.** Без него в канале AI-аналитик (13 сабканалов) приходит
200+ постов двух авторов; с фильтром «слово продукт/разработк + JIRA-ссылка» — единицы.

## Алгоритм

1. Токен `LOOP_TOKEN` из `~/.config/hermes/.env` (или аналог). curl, не requests.
2. Резолв авторов через `/users/autocomplete`.
3. Найди целевой канал по имени + его сабканалы (фильтр по `parent_id`).
4. Обойди каждый канал пагинацией `before`, собери посты.
5. Фильтр: автор ∈ {галашов/жиров} ИЛИ (JIRA-ссылка И ключевое слово).
   Извлеки ссылки `hq.tutu.ru/browse/...` + pid → `https://loop.tutu.ru/tutu/pl/<pid>`.
6. Отдай Саше короткую сводку: ключ + hq-ссылка + Loop-ссылка на пост, от кого.
