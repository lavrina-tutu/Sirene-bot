# Экспорт OKR в Obsidian / таблицы

## Имя per-task файла

`<KEY>_<первые N символов summary, санитизированные>.md` — не голый `<KEY>.md`.

- N — уточнять у пользователя для каждого проекта (прецеденты: 20 → 60 → 100).
- При смене N — переименовать **все** task-файлы, обновить wiki-ссылки (`KEY_` префикс).
- `/\:*?"<>|` → `_`; кириллица в суффиксе допустима (осознанное исключение из ASCII-only obsidian).
- Новая ветка после Jira → сохранить в `okr-tool/<Цель>_<кратко>/`, не только в контексте диалога.

## Иерархия в .md

Годовая → KR → квартальные → их KR. Каждая ветка в своём callout (`[!note]`/`[!tip]`/`[!success]` циклически).

Wiki-ссылки: `[[#Заголовок точного текста|текст]]`, не markdown `#anchor`.
**Экранировать `|` как `\|`** внутри wiki-ссылок в таблицах.

Полные тексты чекина — на одном уровне иерархии; остальные — компактная таблица + раздел сверки.

Callout вверху — минимум: что за файл, откуда данные. Без лишних «рядом лежит бэкап».

## Сводная таблица (закрытие периода)

Первая в файле. Колонки: `Ключ | Obj/KR | Квартал | Название | ФИО | Сверка <период>`.
`Что было сделано` (43822) — обязательная колонка, даже если пустая.
`ФИО` — batch `jql=key in (...)`.

## Таблица «годовая + годовые KR»

Колонки: `Код | Название (ссылка) | Исполнитель | Что планируется | Что сделано | Что надо сделать`.
Пустой чекин → `Чекин пуст — прогресс не зафиксирован в Jira`.

Колонка «Вопросы» (опционально): из `Inbox/`; общие вопросы в каждой строке; `<br>` внутри ячейки, не `\n`.

## Google Sheets

Через `google-workspace`:
- Диапазон без префикса листа (`A1:G8`), не `Sheet1!` — локализованное имя (`Лист1`).
- Явный путь python: `/home/tkachenkoav/hermes-agent/.venv/bin/python3 ~/.hermes/skills/productivity/google-workspace/scripts/google_api.py`
- `TOKEN_REVOKED` → переавторизация; токен → `~/.hermes/profiles/default/google_token.json` (и anthropic при необходимости).
- URL из `[KEY](url)` — отдельная колонка «Ссылка».
- После `update` — `sheets get` на диапазон, сверить первую строку.
