# Meeting Tasks From Text — выявление задач из произвольного контекста

Саша кидает текст (заметку, письмо, поручение, фрагмент чата — НЕ обязательно транскрипт встречи) + говорит, к какому проекту относится. Агент выявляет в тексте задачки и готовит их к заведению в Confluence.

## Текущее состояние (v0.1 — черновик)

Реализовано только **выявление задач** и вывод сущностей по шаблону. Автоматическая запись в Confluence — следующий шаг, НЕ реализована. Задачи в Confluence НЕ создавать без явного подтверждения Саши.

## When to Use

- «выяви задачи из текста», «что тут за задачки», «выведи по промпту саммера»
- Саша даёт текст + контекст проекта и хочет список задач
- Просьба прогнать текст через стандартный промпт суммаризации

## Промпт суммаризации

Единственный каноничный промпт — `ff_summary.json` (тот же, что у MoveFromKeyTalk):
`/home/tkachenkoav/WorkVault/Registries/prompts/ff_summary.json` (id `ff_summary`, version 0.2.0).

Тело промпта (`key "body"`) выделяет сущности по шаблону: **Участники / Обсудили / Решения / Блокеры / Задачи / Риски**. Блок **Задачи** — формат `ФИО: Задача /Срок`.

## Алгоритм

1. Получить текст от Саши + проект (если назван).
2. Прогнать текст по шаблону промпта `ff_summary.json` — извлечь все разделы.
3. **Честность:** если раздел в тексте фактически отсутствует (нет участников/блокеров/рисков) — оставить пустым и пометить `(в тексте явных ... нет)`, НЕ выдумывать. Портrait текста — поручение/план самого Саши, а не транскрипт: там часто нет Блокеров/Рисков.
4. Вывести полный результат по шаблону (все 6 разделов).
5. Задачи (блок «Задачи») — точка входа для последующего заведения через `taskrefresh` (`./tr new`). Пока — только показать список, ждать подтверждения.

## Сигналы для будущей записи (НЕ реализовано в v0.1)

- Приёмник задач: «Общий список задач» (pageId `432316254`) либо «Минутки проекта» (`«<Slug>. Задачи и договоренности (Минутки)»`, page_id в `entities.json` как `pfs.page_id`).
- `project_tag` — каноничный из `project_registry.json` (`WorkVault/Tools/TaskRefresh/project_registry.json`), не выдумывать.
- Запись — только через `./tr new` (см. skill `taskrefresh`), с проектом-префиксом и дедлайном.

## Правила

- Не выдумывать сущности, которых нет в тексте.
- Полный результат = все 6 разделов шаблона, даже если часть пустых.
- Проект не называть от себя наугад: если не указан — спросить Сашу (по одному вопросу, с вариантами и рекомендацией), либо отнести к контекстному проекту только при явной улике в тексте.
- Работать через скиллы `taskrefresh` / `confluence-minutki-creation` для записи — никогда напрямую через curl/API.
