# AnywhereContacts ↔ E.Люди — интеграция (v1.0)

Архитектура интеграции: E.Люди использует AnywhereContacts как источник истины для резолва людей и алиасов. Поддерживаются `add_alias(login, alias, source="aggregate_from") -> bool`, `resolve_name()` и очередь `unclear_names` для неуверенных совпадений.

Подтверждение новых алиасов PM выполняется батчем через F.Дирижёр или вручную TG-командами. После ответа PM запись в `card.md` и хранилище AC делается сразу и атомарно; не дублировать контактные алиасы в `classification_memory.json`.
