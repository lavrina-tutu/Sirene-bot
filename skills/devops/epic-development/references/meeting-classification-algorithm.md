# Алгоритм типизации встреч — AggregateFromMeetings

Зафиксировано по результатам брифа + исследования 478 FF summary (Haiku+Opus, 2026-06-18).

## Статистика из реальных данных

| Метрика | Значение |
|---|---|
| Всего summary | 478 |
| 1on1 | 245 (51.3%) |
| multi | 198 (41.4%) |
| unclear | 20 (4.2%) |
| project | 15 (3.1%) |

**Ключевые находки:**
- Только по названию определяется **66.5%** встреч 1-1 — недостаточно
- 2 участника → **100% точность** для 1on1 (до применения правила проектов)
- **37.6%** встреч 1-1 обсуждают 2+ проекта
- «Синк АиД» ошибочно метится как 1-1 в **18/19** случаях без negative-паттерна
- Название проекта в заголовке **НЕ** определяет тип (Антибот: 54% встреч — 1-1!)

## Финальный алгоритм (приоритет сверху вниз)

```
Ключевой принцип: АЛИАСЫ ПЕРВИЧНЫ, участники и название — вторичны

1. Алиасы/название → ровно 1 проект
   → project (любое кол-во участников, включая диктофон m4a/mp4)

2. participants == 2 (без Fireflies fred@fireflies.ai) + алиасы → 2+ проектов
   → 1on1 (E «Люди» + D для каждого проекта)

3. participants == 2 + нет алиасов проекта + сигнал в названии
   (паттерн: "1-1", "1:1", "Имя-Имя", "Daily Имя")
   → 1on1

4. participants == 2 + нет алиасов + нет сигнала
   → 1on1 (fallback для двух людей)

5. participants >= 3 + паттерн командного синка:
   regex: /синк.*(департамент|аид|гильдия)/i ИЛИ /datatalks/i ИЛИ participants > 5
   → multisync

5a. Диктофон (m4a/mp4) + 0-1 спикеров + нет алиасов проекта
   → multisync (закрытая встреча типа гильдии без FF)
   📌 Фаза 2: уточнять по алиасам

6. participants >= 3 + алиасы → 2+ проектов
   → multisync

7. Алиасов нет + нет паттернов в названии + Haiku confidence == low
   → unclear → F дайджест → PM вручную

8. fallback → unclear
```

**Граница 1on1 vs project:**
- 2 участника + **1 проект** → `project` (только D)
- 2 участника + **2+ проекта** → `1on1` (D + E)

## Типы встреч и маршрутизация

| Тип | Признак | Модуль | Артефакты |
|---|---|---|---|
| `project` | Алиасы → 1 проект | D «База» | decisions, action_items, timeline |
| `1on1` | 2 участника + 2+ проекта (или 0) | D + E «Люди» | D-артефакты + agreements, commitments |
| `1on1+project` | 2 участника + 1 проект | D | только D-артефакты |
| `multisync` | 3+ участников + 2+ темы / командный паттерн | D | все проекты параллельно + Meetings/_syncs/ |
| `unclear` | Нет алиасов + нет паттернов | F → PM | _uncategorized/ |

## Обработка unclear

**Еженедельный дайджест (модуль F):**
- PM получает список всех накопленных unclear встреч
- Для каждой: название + дата + участники + что нашли в алиасах
- PM размечает: `slug проекта` / `1on1 <имя>` / `multisync` / `trash`

**После разметки PM:**
- Если slug/1on1/multisync → обязательный повторный прогон модуля C
- Алиас добавляется в classification_memory.json: `source: pm_manual, confidence: confirmed`
- Если `trash` → `skip: true`, больше не появляется в дайджестах

## TG-команды ручного управления алиасами

| Команда | Действие |
|---|---|
| `встреча [название] → проект [slug]` | Исправить slug + добавить алиас pm_manual/confirmed |
| `алиас [текст] не относится к [slug]` | Заблокировать алиас + пересмотреть встречи → unclear |
| `алиасы [slug]` | Просмотр списка алиасов проекта |
| `удали алиас [текст] из [slug]` | Soft delete (status: deleted), не хард-удаление |

## Промпты

### Bootstrap — Opus (извлечение алиасов из всех summary проекта)

```
SYSTEM: Ты извлекаешь уникальные текстовые алиасы для проекта из встреч.
Алиас = любое упоминание которое ОДНОЗНАЧНО указывает на этот проект.
Критерий: встречается ≥3 раза В ЭТОМ проекте И практически не встречается в других.
Отвечай только валидным JSON.

USER:
Проект: {slug}
Текущие алиасы: {existing_aliases}
Summary {N} встреч:
{summaries}

Верни:
{
  "new_aliases": ["алиас1", "алиас2"],
  "rejected": [{"text": "алиас", "reason": "слишком общее / встречается в других проектах"}]
}
```

### Инкремент — Haiku (классификация новой встречи)

```
SYSTEM: Ты классифицируешь встречу по проекту.
Отвечай только JSON.

USER:
Название встречи: {title}
Keywords: {keywords}
Список проектов с алиасами: {projects_with_aliases}

Верни:
{
  "slug": "project_slug или null",
  "confidence": "high/medium/low",
  "matched_text": "какой текст совпал"
}
```
