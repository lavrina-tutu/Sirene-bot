# Verify skeleton (B0)

Чеклист после каждого PUT (координатор делает повторный GET, не самоотчёт исполнителя).

| # | Проверка | Критерий |
|---|----------|----------|
| 1 | version | = ожидание или честно подхвачена ручная правка |
| 2 | macro count | `ac:structured-macro` не изменился без причины в брифе |
| 3 | section heading | маркер заголовка на месте (не по данным таблицы) |
| 4 | kw not in body | удаляемые значения отсутствуют |
| 5 | no duplicate table | нет дубля `<table>` под одним заголовком |
| 6 | no brief leak | нет «Не копировать», «Уточнить до ПК», «источник:», «см. бриф» |
| 7 | td count | число `<td>` в затронутой таблице = эталону шаблона |

Провал любого пункта → не «успех»; откат к GET-до или повторный патч той же секции.

## CLI

```bash
python3 scripts/verify_skeleton.py \
  --storage /tmp/page_after.json \
  --reference /tmp/page_before.json \
  --heading "Ключевые поставки и сроки" \
  --version 42 \
  --removed "ПИЛОТ" "черновик"
```
