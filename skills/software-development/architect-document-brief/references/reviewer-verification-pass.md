# Ревизорский проход (проверка обработки правок)

После того как архитектор обработал раунд правок заказчика и ПЕРЕД финализацией — заказчик («правила те же, нужен и архитектор и ревизор») требует, чтобы второй агент (ревизор) проверил, как архитектор учёл каждую правку, и согласовал итог.

## Кто ревизор и что ему дать

- Роль: `claude-sonnet-5-medium` (отдельная сессия, БЕЗ `--resume` архитектора).
- Промпт ревизору: прочитать ТРИ файла целиком — (1) версия заказчика с правками, (2) чистая версия архитектора до правок (база), (3) новая редакция после обработки — и сверять по смыслу, не по diff.
- Прямой text-репорт, read-only: ревизор ничего не пишет, только возвращает заключение.

## Что ревизор сверяет (чек-лист в промпте)

1. Каждый комментарий заказчика `*(...)*` из его файла — исполнен ли по существу (перефразировал/разъяснил/учёл), или вынесен обоснованно.
2. Прямые правки/зачёркивания перенесены без искажений.
3. Единая терминология и нет ли противоречий Словарь↔текст.
4. Смысловая целостность не сломана (логика переходов, статусы, условия).
5. Принципы заказчика сохранены (минимальный контур, штатные статусы, всё в штатной Jira, единица — Вопрос).

Ревизор возвращает вердикт + список недочётов (обычно «N некритичных + M вероятных ошибок»).

## Дальше: пачка в архитектора → повторный ревизор

- Передать недочёты ревизора архитектору одним follow-up через `--resume`: по каждому пункту «исправь или аргументированно оставь», помечай `[РАЗВИЛКА]` если нужно решение заказчика.
- Архитектор правит вместе с уже применёнными правками (когда все развилки закрыты, итог вносится в тот же файл).
- Повторный ревизор гонять только если появились новые замечания; если архитектор всё исправил — финальный файл в Outbox и всё.

## Pitfall: полный отчёт ревизора обрезается

`process_manage poll/list` показывает `output_preview` только ХВОСТА отчёта (превью заканчивается на `usage`). Полного текста там нет.

Полный JSON агента лежит в `~/.hermes/logs/process-results/proc_<id>.json`. Достать:

```python
import json
raw = json.load(open('/home/tkachenkoav/.hermes/logs/process-results/proc_<id>.json'))
out = raw.get('output','')
d = json.loads(out)          # это {type:result, subtype:success, result: '<markdown>'}
print(json.loads(out).get('result',''))
```

Либо python-однострочник, который проваливается в `.output → result`. Никогда не отвечай заказчику по недочётам ревизора из превью — сначала достань полный `result` и отдай список целиком.

## Квит заказчику после полного цикла

Отчёт заказчику: что архитектор обработал (сколько комментариев/правок учтено), вердикт ревизора, что исправлено по замечаниям. Финальный согласованный файл — новым/тем же именем в `~/WorkVault/Outbox/`, доставка подтверждена `rclone lsjson`.
