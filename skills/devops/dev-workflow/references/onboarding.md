# Онбординг заказчика

Опишите результат, инструмент и ограничения. Оркестратор принимает поручение, ведёт FIFO и продолжает проверенный маршрут без напоминания; архитектор/ревизор/исполнитель работают по ролям YAML.

Следите за `AC-list.md` и `AC-report.md` в `dev/<slug>/`. Показ AC обычно не требует ответа. Ответ нужен только на явный operator-hold из закрытого словаря (`поднимай`, `ставь кроны`, `удаляй`, `answer:Q-n`, `rollback-to-kanban`) или при доказанном противоречии требованиям.

Не требуется запускать pipeline, raw agent или канбан. Идея попадёт в triage и не стартует сама; готовая задача выполняется в FIFO, пока не будет доставлен финальный отчёт.
