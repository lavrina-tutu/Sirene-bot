# Формат сводки крона vm_dialogbacklog

Актуальный промпт крона vm_dialogbacklog (обновлён 25.06.2026, bk-094).

## Шаг 5 — формат сводки в Telegram

Если новых пунктов нет → `[SILENT]`

Если есть новые пункты:

```
**Бэклог обновлён — N новых пунктов**

Новые:
- `bk-NNN` Текст пункта · _обновлён: ДД.ММ_

Все открытые (всего M):
- `bk-NNN` Краткий текст · _обновлён: ДД.ММ_
```

### Правила формата
- Для каждого открытого пункта `- [ ]` — дата из `updated::` в формате ДД.ММ
- Если `updated::` не найдена → использовать `created::`
- Группировать по секциям из файла (`## заголовки`)

### Где хранится промпт крона
Крон `vm_dialogbacklog` (job_id: vm_dialogbacklog), расписание: `0 9 * * 1` (понедельник 09:00).
Промпт обновляется через `cronjob action=update, job_id=vm_dialogbacklog`.
