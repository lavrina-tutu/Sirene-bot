# MIGRATION-доставка локальному агенту: комплект, а не один файл

Класс: передача плана переезда/переноса локальному Hermes-агенту на другой машине (например R2 — ноутбук Windows). Относится к direct-mode запуску ролей и передаче handoff-материалов между машинами.

## Правила

- **План (MIG-plan.md) не самодостаточен.** §10.1 плана объявляет входной комплект: WINDOWS-HANDOFF.md,
  директива владельца, accepted-decisions, master-amendment, handoff-files.json, JSON-контракты portability,
  полные файлы ревизий (REV-plan[-N].md) целиком, hash-list. Доставка ОДНОГО MIG-plan.md другому агенту =
  DOC-блокер у исполнителя (I01 не закрыт), хотя недостающие файлы есть на машине-источнике. Передавать
  полный комплект §10.1 файлами, затем СВЕРЯТЬ, что каждый вход физически у получателя на диске,
  до объявления B0 выполненным. Ссылка на /home/... чужой машины не считается доставкой.
- **Кроны из delivery активны на целевом хосте по умолчанию.** Импортированные jobs (Linux .sh,
  чужие бэкенды) могут успешно выполнять чужие джобы (restore/sync/rebuild) и вносить правки мимо плана,
  часть падает на отсутствующих .sh — и то и другое шум. B0 обязан доказать их неактивность; если доказать
  нельзя — отключить штатной командой (paused), НЕ удалять jobs/state вручную и не угадывать ключ enabled.
  Бэкап (state.db + WAL + cron/jobs.json) перед отключением обязателен, откат возможен.

## Последовательность передачи

1. Собрать комплект §10.1 из каталога кейса (план + handoff + planning/*.json + evidence/*.md
   полными файлами).
2. Доставить на целевую машину (файлы в чат / выгрузка), положить в целевую папку переезда.
3. Сверить наличие и SHA-256 каждого входа у получателя.
4. Запускать B0 только после сверки; DOC-блокер закрывать доставкой недостающего, а не обходом.

## Питфоллы

- «Агент сам прочитает из сети/архива» — работает только если вход физически на диске у получателя;
  не путать «источник есть на ВМ» с «доставлено на ноут». Локальный агент видит только свой диск.
- Не отдавать исполняющему агенту задачу решать DOC-блокер через самостоятельный поиск «где взять файлы»
  — это его отвлечение; комплект либо доставлен, либо блокер честный.
- Кроны отключать до запуска Desktop/агента (план B0: proof неактивности до B1), не после.
