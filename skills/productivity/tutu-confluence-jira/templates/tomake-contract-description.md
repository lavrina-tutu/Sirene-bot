# Шаблон описания задачи TOMAKE: согласование договора

_Использовать при создании задачи в JIRA проект TOMAKE на согласование нового договора._

---

## Название задачи (формат)

```
Согласовать [тип документа] с [Контрагент] ([ЮЛ туту], [краткое описание])
```

Примеры:
- `Согласовать договор с АО «Неофлекс Консалтинг» (ГМ, пилот Neoflex Dognauts)`
- `Согласовать договор + гарантийное письмо с АО «Неофлекс Консалтинг» (расходный, пилот Neoflex Dognauts)`

---

## Стандартный шаблон описания

```
🎯 ЦЕЛЬ
[Одно предложение — что нужно сделать и зачем]

📋 КОНТЕКСТ
[2–3 предложения: о чём договор, почему сейчас, почему срочно]

⚙️ СХЕМА (если нестандартный процесс)
1. [Шаг 1]
2. [Шаг 2]
3. [Шаг 3]

💰 ПАРАМЕТРЫ СДЕЛКИ
- Заказчик (ЮЛ туту): [ГМ / МБГ / НТТ / ДДС]
- Исполнитель: [Контрагент, организационная форма]
- Тип договора: расходный / доходный
- Предмет: [кратко]
- Сумма: [X руб. без НДС / с НДС]
- Условия оплаты: [напр. 50% предоплата + 50% по Акту, 10 р.д.]
- Срок действия: [дата начала — дата окончания]

📋 МЕХАНИКА
[Как будет работать: формат взаимодействия, что на выходе, удалённо/на площадке]

🤝 КОНТАКТЫ ПАРТНЁРА (для CRM)
- Контактное лицо: [ФИО, должность]
- Телефон: [номер]

- Мессенджер: [Telegram/WhatsApp/другое]

📋 ЭДО
[Диадок / СБИС / другое (роуминг)]

✅ ПРОЙДЕННЫЕ СОГЛАСОВАНИЯ
[ЗК: ссылка на решение, если есть]
```

## Нестандартный случай: старт работ ДО подписания договора

Используется когда:
- Решение о старте принимается в конкретную дату
- Нужна страховка в виде Гарантийного письма
- Договор согласовывается заранее как «проект» для быстрого подписания

```
🎯 ЦЕЛЬ
Предварительно согласовать ПРОЕКТ договора и ПРОЕКТ гарантийного письма,
чтобы при принятии решения [ДАТА] можно было немедленно стартовать работы.

📋 КОНТЕКСТ
[Описание ситуации]
Решение о старте принимается [ДАТА].
Если решение положительное — необходимо начать работы в тот же день.

⚙️ СХЕМА
1. Сейчас (до [ДАТА]): согласуем ПРОЕКТ договора и ПРОЕКТ гарантийного письма
2. [ДАТА] при положительном решении: подписываем Гарантийное письмо → стартуем работы
3. Параллельно: проводим подписание основного договора (дедлайн [ДЕДЛАЙН])
```

## Поля JIRA (REST API)

```json
{
  "fields": {
    "project": {"key": "TOMAKE"},
    "issuetype": {"name": "Задача"},
    "summary": "Согласовать договор с ...",
    "priority": {"name": "Высокий"},
    "description": "...",
    "components": [{"name": "Маркетинг"}]
  }
}
```

**Приоритеты:** `Blocker` / `Высокий` / `Обычный` / `Низкий`  
**Срочное обоснование** — добавить в комментарий к задаче, не в приоритет.
