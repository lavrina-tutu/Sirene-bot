# Дата: 2026-08-27

## Контекст
При выводе контактов (поиск по базе contacts.enc: Loop/exchange/zulip) в Telegram сейчас попадают полные персональные данные — email, username в Loop, департамент, статус активности. Эти же данные записываются в контекст сессий, могут попадать в память (MEMORY), в архивы сессий (session DB), в WorkVault/бэкапы.

## Проблема
Персональные данные сотрудников (email, phones, usernames, паспортные/личные поля) не должны:
1. выводиться на экран (Telegram/чат) в полном виде;
2. храниться в контексте агента и архивах сессий/памяти/бэкапов.

## Задача
Провести ПРОРАБОТКУ (read-only, ничего не менять):
1. Найти и описать текущие места, где персданные контактов выводятся на экран и сохраняются в контекст/архивы (инструменты вывода контактов, session-записи, memory, WorkVault, cron-логи, бэкапы).
2. Определить, какие именно данные чувствительны (email, полные ФИО+должность при открытой выдаче, usernames, телефоны, адреса).
3. Предложить 2-3 варианта решения с оценкой (трейдоффы):
   - (а) маскирование/усечение вывода на экран (например: имя+должность, без email; email — только при явном запросе локально);
   - (б) не писать персданные в контекст/архив/память — сохранять только устойчивый id/метку, данные подтягивать в момент надобности;
   - (в) гибрид (маскирование на экране + исключение из архивов/памяти).
4. Указать конкретные файлы/инструменты/скиллы, которые надо править, и где лежит их код.

Верни структурированный отчёт: найденные места → риски → варианты решения → рекомендация → план пофайловый. НИЧЕГО не изменять, только чтение.
