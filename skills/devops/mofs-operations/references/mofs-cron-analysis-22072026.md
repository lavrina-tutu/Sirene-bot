## Как работает mofs run --mode=cron сейчас

1. **Идемпотентность** — пропускает встречу если `registry[meeting_id].objects_version == "0.6.0"`. Режим `cron` не меняет логику отбора — только формат вывода.
2. **Матчинг** — regex по aliases из entities.json (39 сущностей, 155 aliases). Если regex не нашёл → `extract_candidates` → `llm_fallback` (Haiku, threshold=0.85).
3. **Contacts** — парсинг разделов Участники (3 формата) + резолв в ContactStore.
4. **Индекс** — `reindex_batch` уже встроен в pipeline.py. Bash-скрипт дополнительно вызывает `mofs-index index` — **это дубль, лишний IO**.
5. **Название не используется** для матчинга — только тело summary. Это правильно, но при коротких body даёт `projects: []`.
