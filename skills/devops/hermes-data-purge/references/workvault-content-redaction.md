# WorkVault content redaction (не бэкапы — живоя персоналка внутри vault)

Второй scope чистки при передаче инстанса (первый — state.db purge, второй — бэкапы). Здесь удаляем ЛИЧНЫЕ данные из живого `~/WorkVault/`, сохраняя проектное. Правило Саши: «всю персоналку про меня удалить, про проекты оставить».

## Правила сортировки (в порядке проверки)

1. **Личные папки — удалять целиком**: `Personal/` (резюме, личные рассказы, личные xlsx/фото). Здесь не бывает проектного.
2. **Inbox/ и Outbox/ — ОПУСТОШИТЬ, НЕ УДАЛЯТЬ папки.** Саша решение: папки оставить пустыми, чтобы скилл `workvault-outbox` продолжал работать; только содержимое удалить. Это отличие от обычных папок: сам каталог не rm -rf.
3. **Протоколы 1-1 удалять поимённо** даже внутри проектных деревьев: `Hermes-Backlog/_Archives/*1-1*`, личные `_person*_1-1`. 1-1 инфо — персональное.
4. **Не-md вложения из ЛИЧНЫХ чатов — удалять** (трудовая+2НДФЛ pdf, токены, пароли, фото, скрины из лички).
5. **Оставить**: папки встреч/планов/статусов/проектов (`Meetings/`, `Projects/`, `Hermes-Backlog/`, `Entities/`, `Registries/`, `Tools/`, `_research/`, `Education/`), корневые `.md`, `Contacts/`, `.obsidian/`, все проектные вложения (mpp-планы, договоры zd, КП, артефакты планов). Вложения из Loop по ПРОЕКТНЫМ чатам — оставлять, это проектные данные.
6. **Контакты — по решению Саши оставить**: `Contacts/contacts.enc`, `_meta/AnywhereContacts/events.jsonl`. Это ПДн, но их читает скилл `show-contacts`/AnywhereContacts — спрашивать явно, по умолчанию не трогать, если Саша на связи.

## Подача рецензии

**Рецензия — пронумерованным списком блоков, по номеру** («выведи по номерам»). Группировать верхний уровень vault (каждая папка = блок), для каждого: размер, `🟢 оставить` / `🟢 уже очищено` / `🟡 вопрос`. Под вопросом — тестовые/эталонные/`_meta` папки, перед удалением показать их содержимое. НЕ удалять до явного подтверждения по каждому блоку/группе.

## Order of action
1. `du -sh --max-depth=1` по верхнему уровню vault отдельными `du` на каталог (один широкий `du` может зависнуть на больших деревьях — выводить по одному каталогу).
2. Личные папки rm -rf целиком; Inbox/Outbox — `find <dir> -mindepth 1 -delete` (папку оставить).
3. Протоколы 1-1 и персональные .pdf — точечный `rm -f`.
4. Контрольный `find`/`ls` + `du` на изменённые каталоги, счётчик «папка есть / элементов 0».

## Питфоллы
- **rm -rf Inbox/Outbox** → ломает скилл `workvault-outbox`. Опустошать `-mindepth 1 -delete`, папку сохранять.
- **Один широкий `du -sh --max-depth=1 .`** зависает на крупных деревьях (Hermes-Backlog 1.1G с .venv). Цикл по каталогам, `du -sh` по одному.
- **Удалить все не-md «из чатов» без разбора** → снесёт проектные вложения Loop (договоры, mpp). Критерий — ЛИЧНЫЙ чат, не любой чат.
- **Персональные документы могут лежать в Inbox/Outbox** (трудовая, 2НДФЛ, токены), а не в Personal/ — поэтому при опустошении этих папок они тоже уходят. Это норм по правилу «всю инфу из личной пересылки удалить».
