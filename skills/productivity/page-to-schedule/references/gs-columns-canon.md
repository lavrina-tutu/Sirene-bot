# Канон колонок mpp ↔ Google Sheets

Источник истины форматов: `USERTOOLS/MppReader/gantt_csv_to_gs.py` (длительность, даты) и `push_to_gs.py` (export). **Не** изобретать третий набор.

## Профиль import (страница → GS → потом mpp)

Рабочий профиль, **8 колонок** (канонический порядок):

| # | Заголовок |
|---|---|
| 1 | No |
| 2 | Название задачи |
| 3 | Длительность |
| 4 | Названия ресурсов |
| 5 | Текст1 |
| 6 | Начало |
| 7 | Окончание |
| 8 | Предшественники |

Лист: **`Лист1`** (русская локаль), **не** `Sheet1`, **не** «Задачи» (MppReader создаёт «Задачи» только при записи .mpp).

Диапазон записи: `A1:<col><N+1>` (N строк данных + заголовок). Для 8 колонок: `A1:H<N+1>`.

## Профиль export (mpp → GS)

Скрипт: `USERTOOLS/MppReader/push_to_gs.py`, **16 колонок**:

`№ | % завершения | Название задачи | Длительность | Названия ресурсов | Предшественники | Начало | Окончание | Отклонение окончания | Базовое окончание | Текст1 | Текст2 | Текст3 | Текст4 | Текст5 | Текст6`

## Правила ячеек (оба профиля)

### Длительность

Канон — `gantt_csv_to_gs.fmt_dur`: `N день` / `N дня` / `N дней` по правилам русской грамматики. **Не** `Nд`, **не** только число.

Примеры: `1 день`, `2 дня`, `5 дней`, `10 дней`.

`push_to_gs.fmt_dur` всегда пишет «дней» — для export-профиля это допустимо; для import-профиля (страница → GS) использовать грамматику `gantt`.

### Даты

`gantt_csv_to_gs.fmt_date`: день недели (пн–вс) + `DD.MM.YY`.

Пример: `пн 07.09.26`.

### Предшественники

Номера задач WBS: `3`, `16;5` — без скобок и пробелов.

### Summary-строки (группы)

- Длительность = сумма детей (считает скрипт, не grok).
- Ресурс (`Названия ресурсов`) — пусто.
