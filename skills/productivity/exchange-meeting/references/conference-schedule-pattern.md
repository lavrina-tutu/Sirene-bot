# Паттерн: сохранение расписания конференции в WorkVault

## Когда применять
Пользователь приходит с ссылкой на конференцию и просит сохранить расписание «чтобы потом спрашивать».

## Проблема с JS-SPA сайтами
Многие конференционные сайты (sberuniversity.ru и др.) используют JavaScript-рендеринг (SPA) — поисковые парсеры и `web_extract` возвращают пустой контент. Использовать `delegate_task` с `toolsets=["browser"]` для обхода.

## Путь сохранения
```
/home/tkachenkoav/WorkVault/Conferences/<slug>-<YYYY-MM-DD>.md
```
Пример: `bolshe-chem-menedzhment-2026-06-19.md`

## Структура файла
```markdown
# 📋 Название конференции
**Организатор | Дата | Место + онлайн**
*Тема: «...»*
*Источник: URL*

---

## 🔴 Пленарная программа (онлайн-трансляция)
| Время | Тема | Спикер |
...

## 🟠 Трек 1 — Название
*Аудитория XXX | Кампус ...*
| Время | Тема | Спикер / Модератор |
...

## 🟡 Трек 2 — Название
...
## 🟢 Трек 3 — Название
...
## 🔵 Трек 4 — Название
...

## 👥 Все подтверждённые спикеры
| Спикер | Должность / Компания |
...

> ⚠️ Примечание об источнике данных
```

## Стратегия наполнения
1. Первый заход: парсинг + поиск → сохранить всё что нашлось (темы, спикеры без точного расписания)
2. Последующие сообщения: Саша скидывает расписание по треку → `patch()` нужного трека
3. Патчить трек целиком (заменять блок «темы + спикеры» на таблицу со слотами)

## Связь с календарём
После сохранения расписания — можно создать события в Exchange для интересных докладов.
Паттерн: `categories=["Оранжевый"]`, `legacy_free_busy_status="Busy"`, `reminder_minutes_before_start=0`, `send_meeting_invitations="SendToNone"`.
