# Инварианты tz-workflow

1. **Один master-файл на инструмент:** `WorkVault/Hermes-Backlog/TZ/<Tool>/<Tool>_TZ.md`.
2. **Не распыляться:** доработка существующего инструмента = новая датированная секция в master-ТЗ, НЕ отдельный файл. Точечные ТЗ — только если тема не привязана ни к какому инструменту, тогда `TZ/_misc/TZ-<topic>-<YYYYMMDD>.md`.
3. **Латиница-only** для новых имён файлов/папок в vault (Obsidian).
4. **Версия — только во frontmatter**, не в имени файла. `v1/v2/v3` в имени = старая схема, место в backup.
5. **Содержательный текст ТЗ пишет только Opus.** Sonnet/Haiku делают только механику: переносы, переименования, frontmatter, инвентарь, предварительный сбор зависимостей.
6. **Согласование ТЗ ≠ команда на реализацию.** После финализации текста жди отдельного явного «берём в работу».
7. **Никогда не рестартовать gateway.**
8. **Master-ТЗ остаётся в WorkVault, пока инструмент используется.** Архивация `TZ/<Tool>/` в `WorkVault_backup/...` — только при выводе из эксплуатации.
9. **`TZ/<Tool>/` содержит ТОЛЬКО ТЗ-документы.** Брифы, research-заметки, runtime-state — остаются в структуре инструмента (`USERTOOLS/<tool>/` или `WorkVault/Tools/<Tool>/`).
10. **Backup не копит копии «на всякий случай».** Каждый файл в `WorkVault_backup/` — либо реальный архив выведенного инструмента, либо не нужен.
11. **Полная миграция — значит полная.** Сначала `search_files` по ВСЕМ `USERTOOLS/*` и `WorkVault/Tools/*`, потом перенос.
12. **Инфраструктурные планы** (systemd, RAG, MCP) — по той же схеме `TZ/<Topic>/<Topic>_TZ.md`. Критерий готовности: шаги + verification-команды.
13. **Формат открытых вопросов:** только в разделе `## Открытые вопросы`. После закрытия → `## Решения (дата)`. Решения интегрировать в тело плана.
14. **Связи с экосистемой:** каждое ТЗ обязано содержать `## Связи с экосистемой`. Даже если связей нет — «Нет зависимостей».
15. **Язык:** ТЗ на русском. Технические термины, пути файлов — на английском/латинице.
16. **Промпт субагента** = header из `references/subagent-context.md` + ТЗ. Координационные факты (`[coord]`) отсутствуют.
