**venv:** своего не заводим. Боевой интерпретатор — тот, где уже стоит `exchangelib` и которым пользовались в диагностике: `/home/tkachenkoav/USERTOOLS/AnywhereContacts/venv_linux/bin/python3` + `PYTHONPATH=/home/tkachenkoav/USERTOOLS`. (MeetingScheduler своего venv не имеет.)

### 9.1 Дедуп §4а

```
slot/day МСК aware
  → _ews(start/end)
  → calendar.view(start, end).only(subject,start,end,location,type,is_recurring,uid,organizer)

  → reject neighbor substr
  → item.refresh()

  → UID как ключ серии (сравнить, не restriction)
```

Master: `filter(subject__icontains='Синк 1-1 Саша')` без `start__range`; на клиенте `type==RecurringMaster` + aralov.

Busy: `Configuration(retry_policy=FaultTolerance(max_wait=120))`; узкий view (сутки); `.only` без attendees; `sleep(e.back_off or 60)`.

### 9.2 Переговорки §5

Порядок: свободные 4–8 МСК → исключить Лес/Кабинет → назначить → `refresh` + `resources[].response_type in {Accept, Tentative}` → иначе следующая → нет 4–8 → ёмкость 2 («Два стула (2)») → нет → `только ВКС`.

Формат Места: `{Имя} ({cap}) - Zoom`. Имя без дублирующего суффикса Zoom. Без комнаты: ровно `только ВКС` (не Zoom URL MS).

Контроль: (а) сразу `wait_room_acceptance`; (б) VCS живёт до следующего четверга и снова классифицируется как `bad_place`.
