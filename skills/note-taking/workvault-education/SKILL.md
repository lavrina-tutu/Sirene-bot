# WorkVault Education — курсы и знания

Саша хранит учебные курсы и прочие знания в корне WorkVault.

## Принцип сохранения курсов (клчевое)

**Каждый курс — отдельная папка `Education/<slug-курс>/` с файлами:**
- по одному md-файлу на урок, нумерация `01-`, `02-`, ... в порядке преподавания (чтобы Сирень могла пересказать последовательно, как учили);
- `README.md` — карта курса: оглавление со ссылками на все файлы уроков + ссылка на НАСТОЯЩИЙ источник (для форка/перевода — отдельно оригинал и отдельно форк, явно помечено).

## Структура (вариант A — согласовано)

```
WorkVault/Education/
  Knowledge/                  # прочие знания: статьи, заметки, конспекты вне курсов
  <курс>/                     # по одной папке на курс (напр. learn-claude-code-rus/)
    README.md                 # карта курса: оглавление + ссылка на настоящий источник
    01-<урок>.md, 02-<урок>.md ...  # по одному файлу на урок, в порядке преподавания
```

- **Папку курса создавать до наполнения**, чтобы был скелет.
- **Пустые подпапки не плодить заранее** — `Knowledge/` обязательно, дальше по мере необходимости.
- Кириллица в имени папки допустима для удобства чтения, но согласованный шаблон — латиница/слиз (курсы называются как репо/бренд: `learn-claude-code-rus`).

## Формат курса (предпочтение Саши)

- **По одному md-файлу на урок**, в порядке преподавания (нумерация `01-`, `02-`, ...), плюс `README.md` как **карта курса** (оглавление со ссылками на файлы уроков). Не один файл на весь курс.
- **README обязан содержать ссылку на НАСТОЯЩИЙ источник курса** (для форка/перевода — и на оригинал, и на форк, явно помечено какой какой).
- **Детализация по запросу Саши**: он просил «с деталями, чтобы ты сама могла рассказать в той последовательности, в которой преподают» — разбор урока сохраняется структурно (проблема → решение → ключевые детали → схема потока → итог/девиз → попробуй сам), чтобы Сирень могла пересказать курс по-порядку, а не пересказ-сжатие.
- **Без лишней кодовой базы, без картинок.** Не вставлять код-фрагменты целиком; сохранять смысловые схемы и названия структур/инструментов.
- Термины и аббревиатуры курса расшифровывать при первом упоминании.
- Признаки триггера курса — «запиши себе в education», «все уроки курса в md».
- **Только литературный русский, минимум жаргонизмов.** Саша хранит курсы для чтения на русском: убирать англицизмы («промпт»→системная инструкция, «ревью»→проверка кода, «паттерн»→приём, «кейс»→случай, «деплой»→выпуск), сохраняя технические имена, у которых нет русского эквивалента (Claude Code, git diff, YAML, названия моделей).
- **Имена файлов уроков — как в оригинале курса** (латиницей/на языке источника: `01-what-are-subagents.md`), НЕ переводить на русский (`01-что-такое-субагенты.md` — не надо). Внутри файла текст — литературный русский. Так в Obsidian видно структуру курса как у источника, а чтение — на русском.
- **Если при разборе добавляю собственный анализ/сравнение сверх материала курса** — помечать отдельный раздел заголовком «Размышление Сирени» с явной пометкой, что это не материал официального курса, а собственная интерпретация для Саши, чтобы не спутать с оригиналом (пример: сравнение «proactively»-субагента vs автономного агента по доске).
- **«Заметочка» по просьбе Саши — записывается в файл урока.** Если Саша просит «запомни», «зафиксируй», «сделай заметочку» по ходу разбора урока (напр. «зафиксирую разницу…») — ОБЯЗАТЕЛЬНО оформить это отдельным разделом «Размышление Сирени» в файле этого урока (не только ответить в чате): сформулировать различие/факт литературным русским, с той же пометкой о неофициальности («это не материал официального курса, а собственное размышление Сирени»). После внесения — доложить Саше одной строкой, что заметка сделана и где она лежит (файл урока + название раздела).

## Два сценария входа — всё делать идентично

Оба сценария приводят к ОДНОЙ и той же структуре папок и формату конспекта выше. Разница только в том, откуда Сирень берёт материалы.

### Сценарий 1: Саша дал ссылку на курс
Фразы-триггеры: «сохрани курс», «загрузи», дал URL + просит сконспектировать.
Ссылка → определить источник → достать материалы → законспектировать.

**Источники и как с ними работать:**
- **Git-репозиторий/форк** → `git clone --depth 1 <репо> ~/.hermes/cache/scratch/<short>/` (всегда в scratch), искать `docs/{rus,en}/` (`docs/rus/` обычно полнее en), читать уроки, после — `rm -rf` клон.
- **Веб-курс/платформа (напр. Claude Academy `academy.claude.com`)** → сначала поиском найти настоящий источник и курс (уроки открыты публично, login только для сохранения прогресса). `web_extract` может отклонить домен как «private/internal network address» — это ложный блок; рабочий путь — `browser_exec`: открыть страницу курса (контент рендерится через JS, `page_info`/`innerText` на пустой загрузке), собрать ссылки `a[href*='<course-slug>']` → это и есть уроки в порядке преподавания. **Эффективно собирать ВСЕ уроки одного курса одним прогоном browser_exec**: у каждого `goto_url` → `wait_for_load()` → пауза ~5 c (JS-рендер) → взять `js('document.body.innerText')` и накопить в один временный файл workspace, затем прочитать его `read_file` и писать русские конспекты по-уроку; временный файл-транскрипт после записи удалять. Ссылку-источник (URL оригинала) сохранить в README.
- Ссылку-источник (URL оригинала) сохранить в README.

### Сценарий 2: Саша просто выгрузил материалы
Фразы-триггеры: «вот материалы», «дропнул файлы», прикрепил md/дамп/транскрипт/артефакт.
Файлы могут лечь куда угодно (вложение, файл, Inbox). Сирень:
1. Определяет название курса/темы из содержимого или имени файла → создаёт `Education/<slug>/`.
2. Раскладывает полученные материалы по смыслу: если это цельный курс по урокам — разбить по-уроку в `01-`, `02-`, ...; если единый документ — разделить по разделам; без насильственного разрыва.
3. Если автором присвоено имя/порядок — сохранить его как есть.
4. Если курс известен (можно установить источник) — добавить ссылку в README; если источник неизвестен/внутренний документ — в README указать «материалы предоставил Саша, источник не публичный».

В обоих сценариях итоговый результат БУКВАЛЬНО тот же: отдельная папка, README-карта с источником, файлы по-уроку — чтобы Саша не различал «по ссылке» vs «выгрузка».

## Процедура захвата курса из репозитория

1. Проверить `<available_skills>` — курс может быть уже частично разобран (search vault first). Параллельно с чтением репо искать совпадение по имени курса.
2. `git clone --depth 1 <репо> ~/.hermes/cache/scratch/<short>/` — всегда в scratch, не в vault.
3. Искать раздел документации: `docs/{ru,en,...}/`. **Русская версия полнее англ.** — при наличии `docs/rus/` брать её как основу.
4. `read_file` каждый урок (не `cat`) → сохранить разбор по формату выше, по-уроку по порядку.
5. `write_file` по одному файлу на урок + `README.md` карту с оглавлением и ссылкой на настоящий источник.
6. `rm -rf` клон из scratch (мусор не оставлять).

## Питфоллы

- **«Стоп» отменяет план, но не структуру.** Запросили создать папку — создавайте; но САМ конспект курса не писать, пока нет явного «да» (прошлый «да» + новый «стоп» = стоп).
- **Не давать официальный курс Anthropic за аналог ру-форка**: `learn-claude-code-rus` (форк shareAI-lab, учит строить агента самому) ≠ `Claude Code 101` (офиц. Anthropic, учит пользоваться готовым инструментом). Сравнивать по источнику и фокусу, а не по имени.
- **Забирать суть из полной русской версии, а не из коротких en-файлов** — `docs/rus/` в этом репо значительно объёмнее и детальнее `docs/en/`.
- **При переводе уже сохранённого курса в литературный русский — переводить только содержимое, имена файлов сохранять как в оригинале курса.** НЕ делать русские названия файлов и не удалять английские имена: структура и ссылки в README должны оставаться как у источника.
- **Оглавление курса (curriculum) может содержать дубликаты уроков** в разметке страницы — это артефакт, не повтор. Сводить к уникальному списку.
- **Курс может заканчиваться квизом/итоговой проверкой без контента** (напр. «Final assessment on MCP» в MCP-курсе, `final-assessment-*`/`badge`/`complete` в списке ссылок) — НЕ делать из него файл урока, а в README пометить, что финальная проверка квизом не включалась в конспект.
- **Переименование файлов уроков через `mv` не оставляет дублей** — если Саша говорит «синк не прошёл / удали лишние», проверять наличие дублей в Education точечно (часто их нет); если дублей нет, диагностировать сам сбой синка (лог `~/.local/share/hermes/logs/owncloud-sync.log`), не чистя файлы курсов вслепую.
- **Файлы уроков релевантны для последующего «пообщаться по курсу»** — Сирень должна быть готова отвечать по сути любого урока из сохранённых файлов, а не заново клонировать репо. Питфолл при захвате курса с Claude Academy (Skilljar): полноценный прогон уроков часто требует авторизации/интерактива — сначала проверить открытую публичную базу (страницы курса + открытые тексты), сохранять с пометкой о неполноте или просить Сашу залогиниться в browser-сессии; не выдавать внешний конспект за дословный курс.
- **«А у нас это есть?» при разборе урока — сверять с реальными исходниками Hermes, не отвечать по памяти.** Саша после каждого урока спрашивает, реализовано ли то же в Hermes (allowed-tools, валидатор скиллов, отчёт о препятствиях и т.п.). Курс учит механизмам Claude Code; у Hermes те же возможности часто называются и устроены иначе (напр. `allowed-tools` во фронтматтере не читается — есть `allowed_toolsets` субагента и условия активации `metadata.hermes.requires_toolsets`, отдельной команды-валидатора нет). Искать ответ в установленном коде: workspace по editable-finder (`__editable___hermes_agent_0_0_0_finder.py` → MAPPING → `workspace/agent`, `workspace/hermes_cli`) или `~/hermes-workspace`; называть конкретные механизмы и их отличие от курса, а не «да/нет» без оснований.
- **В `browser_exec` путь рабочего каталога брать через `os.environ.get("BH_AGENT_WORKSPACE")`, а не через переменную `workspace`** — в коде шага она может быть не определена (`NameError: name 'workspace' is not defined`). Временный файл-транскрипт писать по env-пути (с запасным абсолютным путём), после записи конспектов удалять.
- **`web_extract` может вернуть «Blocked: URL targets a private or internal network address» на legit-домен курса** (academy.claude.com) — это ложный отказ инфраструктуры, не признак приватности или недоступности. Не бросать источник: переключиться на `browser_exec`, контент на таких платформах рендерится через JS.
