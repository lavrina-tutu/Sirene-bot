# Moscow Suburban Train Schedule Lookup

## Trigger

Саша спрашивает: «на какой путь прибывает электричка на X?», «во сколько электричка в Y?», «какой поезд в HH:MM с Ярославского?».

## Key Insight: rasp.yandex.ru не открывается через web_extract

`rasp.yandex.ru` возвращает `Error fetching content` при web_extract.  
`rasp.yandex.kz` (казахстанский домен) **работает** для страниц конкретного поезда.

⚠️ Время на rasp.yandex.kz — **астанинское (UTC+5)**, московское = астанинское − 2ч.

## Алгоритм поиска

### Шаг 1 — найти номер поезда

```
web_search("поезд {HH:MM} {начальная станция} {конечная станция} Ростокино путь")
```

Пример: `"18:30" Ярославский Пушкино Ростокино путь`

Яндекс Расписания часто показывает номер поезда и путь прямо в сниппете поиска.

### Шаг 2 — получить полное расписание

URL-паттерн для web_extract:
```
https://rasp.yandex.kz/thread/R_{номер поезда}_{ID начальной станции}_g25_4
```

### Шаг 3 — верифицировать путь

В таблице расписания находим строку со станцией, читаем поле «N путь» в ячейке.

## Питфоллы

- **rasp.yandex.ru** — не открывается через web_extract (Error fetching content). Не пытаться повторно.
- **tutu.ru** — блокирует web_extract ("Blocked: URL targets a private or internal network address"). Не использовать.
- **Время на rasp.yandex.kz** — астанинское, −2ч к московскому. Пересчитывать перед ответом Саше.
- **Сниппет поиска** часто содержит путь прямо в описании — проверять до лишнего web_extract.
- Расписание **по будням ≠ по выходным** — уточнять если запрос на выходной день.
