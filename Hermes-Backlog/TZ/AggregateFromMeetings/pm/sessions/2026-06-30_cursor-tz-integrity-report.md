## 2. Что внесено в этом цикле (Q-B + Q-C)

### Формат PM Notes (PD-053…058, Q-B1…B7)
- Блок `### PM Notes (tasks|decisions|risks)` под секциями среза; маркеры `_ADD` / `_DELETE` / `_UPDATE` + свободный комментарий.
- ID сущностей `^{slug3}{hex}` (Obsidian block reference); счётчики в `state.json.last_ids`.
- `_ADD` задачи → секция `## ✅ Задачи (добавлено PM)`; `_DELETE` = физическое удаление; `[x]` = выполнено; `_UPDATE` в срезе = перезапись без истории (история — в карточке D).
- Поиск объекта — Haiku по смыслу.

### Закрытие открытых вопросов (Q-C1…C3)
- **Q-C1** — маппинг секций среза → 3 блока (Решения+Блокеры→decisions, Риски→risks, В работе+Следующие шаги→tasks; Открытые вопросы/Сделано — без блока).
- **Q-C2** — единый формат tasks/decisions/risks для всех доменов (1-1 и синки маппятся на те же 3 типа).
- **Q-C3** — `short_id` явно в `card.md` + реестр уникальности + авто-кандидат.
