# Каталог полей шаблона ПРО (устав / бриф)

Фиксированный набор полей официального шаблона проектных документов Туту. Патч — только секция по маркеру-заголовку (B0 `section_patch`).

| Поле | Примечание |
|------|------------|
| Параметры | Сроки реализации = `<time datetime="YYYY-MM-DD" />` (Confluence Date Lozenge) |
| Контекст | Предыстория, обоснование |
| Что получит Туту | Эффекты для компании |
| Если проекта не будет | Альтернатива / последствия отказа |
| Как заказчик поймёт | Критерии успеха для заказчика |
| Цель | SMART-формулировка |
| Финмодель | Экономика проекта |
| Описание и границы | Scope / out of scope |
| КТ | Контрольные точки |
| Критерии приёмки | Приёмка результатов |
| ИСР | Иерархическая структура работ |
| Календарный план | Вехи и сроки из MPP |
| Ресурсный план | Роли и загрузка из MPP |
| Ключевые поставки и сроки | Закупки, лицензии, внешние поставки |
| Бюджет | Внешние (договор вендора) + ФОТ (часы MPP × ставка) |
| Реестр стейкхолдеров | Роли, user-mention где возможно |
| Матрица коммуникаций | Каналы и частота |
| Допущения | Допущения проекта |
| Ограничения | Ограничения проекта |
| Реестр угроз и рисков | Риски из MPP и реестра |

Пачки grok (3, не 17):
1. **MPP** — Параметры (сроки), Описание и границы, КТ, ИСР, Календарный план, Ресурсный план.
2. **Стратегические** — Что получит Туту, Если проекта не будет, Как заказчик поймёт, Цель, Финмодель, Ключевые поставки и сроки, Бюджет (текст; цифры — скрипт).
3. **Контекстные** — Контекст, Реестр стейкхолдеров, Матрица коммуникаций, Допущения, Ограничения, Реестр угроз и рисков.
