# Независимый расчёт контрольных дат

Источник ожиданий: вручную заданный граф, не локальный scheduler. Часовой пояс
наблюдения Europe/Moscow. Рабочая неделя пн–пт, интервалы 09–12 и 13–18 (8 часов).
A вручную закреплена с 07.01.2026 09:00 до 08.01 18:00, длительность 2 дня.
B — 1 рабочий день. FS даёт 09.01, SS — 07.01, FF — 08.01. Для SF конец
B равен началу A (07.01 09:00), начало B — 06.01 09:00: ночной перерыв
между 06.01 18:00 и 07.01 09:00 не увеличивает рабочую длительность.

FS +2 дня: 13.01; FS −1 день: 08.01. FS +2 часа: 09.01 11:00–12.01 11:00,
поскольку в пятницу после 11:00 остаётся 6 рабочих часов, остальные 2 — в понедельник.
Нерабочая пятница 09.01 сдвигает B на понедельник 12.01. Исключение с рабочим
окном 10–11 в пятницу даёт 09.01 10:00–12.01 17:00 (1 + 7 часов).
Ресурсные назначения FixedDuration с units 0 и 50 не меняют даты B.

Коды типов прочитаны из DependencyModel.Type установленного браузерного плагина,
затем подтверждены рассчитанными датами. `eday` дал runtime error `Conversion
unit not provided`; другая elapsed-кодировка не проверена. Для elapsed нет
проверенного расчёта, статус not_verified; поддержка не заявляется.

Первые контрольные наблюдения сверены с этими ожиданиями. Эталоны далее
проверяются повторным реальным прогоном, без подстановки входных дат.
