# Подсчёт уникальных людей/объектов на Miro-доске + дедупликация

Реальная задача (14.09): посчитай, сколько человек в оргструктуре на фрейме.
Карточки-люди = sticky, один человек может быть на 2+ карточках (разные отделы/роли)
и в разных формах имени.

## Подводные камни
- `board_search_boards` не отдаёт modified_at/created_at → нельзя найти «последнюю правленную» доску по API.
- Один фрейм может описывать прошлую/сравнительную версию: title фрейма несёт даты («актуальная - 14.09.26» vs «- 26.05.26») — выбирать по смыслу.
- `canvas_search(matches)` → результаты имеют `parent` = фрейм-владелец. Один и тот же человек встречается в `parent` актуального и сравнительного фреймов — править/считать только в том, который запрошен («более ничего не меняй»).
- Заголовок на самой доске часто содержит число исхода («Департамент аналитики и данных (80)») — это число карточек ДО дедупликации, НЕ число уникальных людей.

## Скрипт дедупликации (python3, over kvadrants → list)
Форматы имён отличаются: «Фамилия Имя» и «Имя Фамилия», уменьшительные («Лена»/«Елена», «Саша»/«Александр»).

```python
import re
from collections import defaultdict

names = [
 # все sticky-имена из всех прочитанных квадрантов, С ПОВТОРАМИ как на доске
]
ALIAS = {"лена":"елена","юля":"юлия","настя":"анастасия","саша":"александр",
 "таня":"татьяна","наташа":"наталья","влад":"владислав","володя":"владимир",
 "коля":"николай","лера":"валерия","юра":"юрий","настя":"анастасия"}

def tokens(name):
    name = name.replace('ё','е').replace('Ё','Е')
    return [t.lower() for t in re.findall(r"[А-Яа-я]+", name)]

def pair_key(name):
    toks = tokens(name)
    if len(toks) < 2:
        return (None,)*2
    a = ALIAS.get(toks[0], toks[0]); b = ALIAS.get(toks[1], toks[1])
    return frozenset([a,b])  # порядок не важен: Фамилия-Имя или Имя-Фамилия

groups = defaultdict(list)
for nm in names:
    groups[pair_key(nm)].append(nm)

uniq = len(groups)
dups = {k:v for k,v in groups.items() if len(v)>1}
print("Всего карточек:", len(names))
print("Уникальных людей:", uniq)
print("Группы с повторами:")
for k,v in dups.items():
    print("  Повтор x%d:"%len(v), sorted(set(v)))
```

## Результат в прошлой задаче
80 карточек → 75 уникальных. Дубли: Цветкова Елена x3 (в т.ч. «Цветкова Лена»),
Ларьков Саша x2, Цыба Леонид x2, Белов Алексей x2.
