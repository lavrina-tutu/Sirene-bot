|---|---|---|---|

| 3 | Коммерческие условия | Условия оплаты, сроки, объём | ✅ |

| 6 | Кто подтверждает оплату в JIRA | Только для расходных договоров | ✅ расходный |
| 7 | Механика | Как это будет работать (процесс) | ✅ |
| 8 | Способ взаимодействия с партнёром | Через БЗ или напрямую с АМ | ✅ |
| 9 | Контакты партнёра для CRM | ФИО, должность, тел., email, мессенджер | ✅ |
| 10 | ЮЛ туту | ГМ / МБГ / НТТ / ДДС | ✅ |
| 11 | Срок действия договора | Даты начала и окончания | ✅ |
| 12 | Ожидаемые сроки согласования | Желаемая дата подписания | ✅ |
| 13 | Возможные риски | Начальный анализ от БЗ | ⚠️ если есть |
| 14 | Драфт договора | Файл договора | ✅ |
| 15 | Уставные документы партнёра | Если уже запрошены / контрагент прошёл закупочную комиссию | ⚠️ если есть |
| 16 | ЭДО партнёра | Диадок / СБИС / другое (роуминг) | ✅ |

## Уставные документы по типу контрагента

- **ЮЛ:** актуальный список — [Confluence pageId=61966518](https://dom.tutu.ru/pages/viewpage.action?pageId=61966518), раздел «Этапы → Запрос документов у контрагента»
- **Самозанятый:** скан паспорта (разворот ФИО + регистрация), ИНН (скан), СНИЛС (скан)
- **ИП:** ИНН (скан), ОГРНИП или лист записи о создании (после 2017), основание освобождения от НДС (если применимо)

## Поля задачи TOMAKE в JIRA

| Поле JIRA | Значение |
|---|---|
| Проект | TOMAKE |
| Тип задачи | Задача |
| Название | `Согласовать [тип] с [Контрагент]` |
| Компоненты | Маркетинг (для маркетинговых/расходных) |
| Приоритет | Обычный (обоснование высокого — в комментарии) |
| Исполнитель | Назначается автоматически |
| Описание | Все поля из таблицы выше |
| Вложение | Заполненный шаблон договора/ДС/Заявки |
| Срок | Желаемая дата (не гарантируется) |

## Путь: новый договор vs. ДС/Приложение

- **Новый договор** → АДД «Нужна помощь аккаунт-менеджеров» → «Договор (расходный/доходный)» → автоматически создаётся задача MIX
- **ДС/Приложение/Заявка к существующему** → напрямую в TOMAKE, за 2 недели до старта

## Статусы задачи

- `Сделать` — задача в очереди у аккаунта
- `В работе` — аккаунт активно работает
- `Требуется доработка` — вернули автору (нужно дополнить описание/кодировки/суммы)

## Ключевые правила

> Договор согласовывается **ДО** даты фактического начала оказания услуг / выполнения работ.
>
> Оплата производится **по факту подписания договора**.
>
> Если изменились коммерческие условия, механика или тип договора — **новая задача АДД**, не правки в старой.
