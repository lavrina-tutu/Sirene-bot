# План-график из Confluence-страницы → Google Sheets (mpp→GS формат)

Как построить план-график работ по доработке платформы/проекта из Confluence-страницы и залить в GS в формате, который легко переносится в MS Project. Отработано на двух вариантах плана доработки AB-платформы (страницы 514903239 и 519489611).

## Пайплайн

1. **Скачать страницу-источник** через ConfluenceSync:
   `python3 -m confluencesync pull <pageId> --no-recursive --resync`
   Найти локальный path: `grep -rl "<pageId>" ~/WorkVault/Confluence --include=index.md`.
   Если файл бинарный (NUL) — читать через `tr -d '\000' < file`.

2. **Собрать бриф для архитектора** (через codex CLI, gpt-6-astra): передать фичи/поля из страницы, исполнителя, дату старта, формат вывода. Ключевые вводные:
   - Исполнитель (обычно 1 ресурс, 100%)
   - Дата старта (напр. 07.09.2026)
   - Маппинг полей страницы → колонки плана (уточнять у Саши, напр. «Фича→Название, Чего не хватает→Комментарий, Сложность→Длительность»)
   - Формат вывода = шаблон mpp→GS (см. ниже)

3. **Архитектор выдаёт план** таблицей + TSV-блоком. Проверить: длительности «N дней», даты «пн 07.09.26», предшественники, summary-строки.

4. **Создать GS** через `page-to-schedule` / `push_import_gs.py`:
   - OAuth reuse MppReader `get_services()`
   - Заполнить через Sheets API, диапазон `Лист1!A1:H<N+1>` (лист по умолчанию «Лист1» в русской локали, НЕ Sheet1).

## Конвертация сложности → дни (скрипт, не grok)

- «Менее 1 недели» → 3 дня
- «1 неделя» → 5 дней
- «1-2 недели» → 10 дней
- **Если сложность пустая — fail-loud** (не «оценка архитектора»); явная оценка только в брифе координатора.

## Формат mpp→GS (шаблон Саши)

Колонки: `No | Название задачи | Длительность | Названия ресурсов | Текст1 | Начало | Окончание | Предшественники`

- Длительность → `N дней` (целое + «день/дня/дней», НЕ «Nд» — иначе Project не поймёт)
- Даты → `пн 07.09.26` (день недели + `%d.%m.%y`)
- Предшественники → номера задач (`3`, `16;5`), без скобок/пробелов
- Summary-строки (группы): длительность = сумма подзадач, ресурс пусто

## Питфоллы

- **Праздники РФ** — `page-to-schedule/references/rf-holidays.yaml`; скрипт не считает 31.12–08.01 рабочими.
- **Конфликт ресурса**: если тот же исполнитель занят в другом проекте, планы не совмещаются без удлинения — отметить в резюме.
- **Диапазон записи GS**: N строк данных + заголовок → диапазон `A1:H<N+1>`.
- **Лист по умолчанию «Лист1»** (русская локаль), не «Sheet1» — `values().update` с Sheet1 падает `Unable to parse range`.
