# Дизайн GLOSSARY + однозначность терминов

Архитектор спроектировал, как хранить глоссарий и повысить однозначность терминов с учётом документации Hermes, цепочек и экосистемы.

## Рекомендация: три слоя, один канон
1. **Канон** `~/WorkVault/Hermes-Backlog/TZ/GLOSSARY.md` — единый источник правды, версия в YAML, владелец ProcessImprovement. 3-5 КБ (~1-2k ток). Не инжектится сам → не жрёт токены постоянно.
2. **Компакт-индекс в USER.md** (~210-386 симв.): коллизии + путь. Влезает в цель ≤1000. TG-бриф (Сирень, cwd=~) видит USER всегда.
3. **Якорь в `TZ/AGENTS.md`** (4-6 строк) — только когда cwd=каталог ТЗ (Cursor `cd TZ`).
4. **Обязательный `read_file` канона** в `tz-workflow` и `hermes-feature` до первого `PREFIX:фаза`.

**Отклонено:** встраивать полный глоссарий в tz-workflow/hermes-feature (дубль+дрейф, на карточке 1 скилл); отдельный скилл-глоссарий («No router/index/hub» в doc, Саша против плодить скиллы); полный текст в USER/MEMORY (лимиты, процедуры в память нельзя); в `~/AGENTS.md` (каждая сессия Loop/Jira/SR).

## Структура глоссария (обязательно)
Правила чтения (PREFIX:фаза, первое упоминание) · Слои токенан (кейс≠роль≠скилл≠документ≠фаза) · Кейсы 8 · Роли+модели · Скиллы пайплайна · Фазы по префиксам · Гейты · Артефакты и пути.
Опционально: 48 инструментов → указатель на MAIN_TZ_INVENTORY; канбан-id `devpipe:<slug>:<phase>`.
**Не включать:** процедуры HITL, графы parents, промпты компрессора, кроны.

## Правила однозначности
- **Нейминг фаз**: `PREFIX:kebab-case`. Префикс = слой, не кейс.
  BRF=бриф в TG(не карточка); GATE=гейт Саши; TZ=фаза записи ТЗ; HF=фаза hermes-feature; ORCH=только фаза shared-state; REV/BUG/RS/MIG/DEC/SK.
- **Запрет** голых BRF/HF/ORCH, `DEV:impl`, синонимов `HF:fix`→`HF:impl`, `TZ:architect` как бриф.
- **Первое упоминание**: `HF:impl (реализация, скилл hermes-feature)` → дальше канон.
- **Коллизии**: TZ ≠ tz-workflow ≠ «ТЗ»; HF ≠ hermes-feature; ORCH ≠ оркестратор; DEV ≠ исполнитель.

## Подгрузка (не живёт сам по себе)
| Момент | Кто | Что | Механизм |
|---|---|---|---|
| Любая TG-сессия | Сирень | компакт коллизий | USER.md всегда |
| Бриф | Сирень | полный канон | tz-workflow шаг 0: read_file |
| TZ-фазы | архитектор Cursor | якорь+канон | TZ/AGENTS.md + agent -p путь |
| HF-хвост | исполнитель | то же | hermes-feature шаг 0 |
| Канбан | воркер 1 скилл | канон | шаг 0 фазы |
| Loop/Jira/SR | Сирень | только компакт | полный не читать |
| Cron/agent -p | нет USER | канон в промпте/read | hermes-feature |
