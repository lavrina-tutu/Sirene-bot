# Д4 — решение владельца, 17.11.2026

Источник: прямое поручение Саши в текущем сеансе Codex.

«Каждый новый план с наиболее поздним изменением файла считаем актуальным. Просто фиксируем в архиве и отражаем а конфлюенс. При вопросе по истории сообщаем что задача добавилась или удалилась и какие ее связи».

B/C: историческое правило не применяется (решение владельца). Связь UID510→UID323 сохраняется; исключение не требуется, историческая ревизия не активируется.
D: назначение без ресурса публикуется как есть (resource_uid: missing). Исходные назначения/интервалы/работа сохраняются; ресурс пустой, без выдумывания исполнителя.

Веха UID373 «Согласован старт проектных работ Пилот, ресурсы выделены» (WBS 1.2): в конечном MPP всё верно — веха это веха, длительность 0. Противоречивый исходный интервал (start 30.03.2026, finish 22.04.2026) публикуется как есть: плагин рисует веху точкой на одну дату; обе даты остаются в архиве; к вехе применяется пометка «интервал вехи сжат при отображении». MPP не правится. Если в последующих планах смысл вехи изменится и она станет задачей — применяется то же правило: актуален последний план.

Числа A–D и полный gate §20 не меняются.
