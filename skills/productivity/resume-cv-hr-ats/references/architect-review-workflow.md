# Бриф архитектору: анализ резюме (сверка с рынком РП)

Происхождение: адаптировано из resume-optimization (license: proprietary); перенос не означает перелицензирование в MIT.

## Назначение
Саша: «проанализируй резюме с архитектором на соответствие лучшим практикам / где бы ты усилил». Вердикт и комментарии — от архитектора (Codex `gpt-6.1-sol`, effort high), не от Сирени в чате.

## Шаблон брифа (структура)
Реальный пример: `~/WorkVault/Personal/resume/резюме_бриф_архитектору_20261026.md`; бриф на анализ — в `scratch/resume_arch_brief_*.md`.

1. Роль: «архитектор (профессиональный вердикт по резюме руководителя проектов)». Задача = АНАЛИЗ И КОММЕНТАРИИ, не переписывание.
2. Workspace: `~/WorkVault/Personal/resume`.
3. Файлы для чтения (пути, «прочитай сам»): анализируемый revN (Outbox), фактура `resume_final_faktura_*`, архив переписки, предыдущий вердикт архитектора.
4. Требование Саши дословно (цитата) + структурированная расшифровка.
5. Требования к выводу:
   - потекстовые комментарии по разделам с пометками приоритета `[ВЗЯТЬ В РАБОТУ]` / `[ОПЦИОНАЛЬНО]` / `[НЕ ТРОГАТЬ — решение Саши]`;
   - каждое предложение — конкретное (формулировка) и с обоснованием практикой/вакансией, НЕ выдуманное;
   - рыночная сверка по 2–4 вакансиям РП (URL + какие требования резюме закрывает/не закрывает);
   - раздел «Детали на заполнение Сашей» `[вставить]`;
   - НЕ выдумывать факты/цифры; НЕ переписывать сам черновик; принцип «компания только в своём блоке»;
   - результат — файл `~/WorkVault/Personal/resume/резюме_анализ_архитектор_<date>.md`.

## Запуск

Использовать актуальный канон скилла `codex` для архитектурной консультации и действующую конфигурацию; не применять устаревшие жёстко заданные модели или команды из исторического примера.

## После
- Результат отдать в топик-источник (MEDIA-путь) + краткое саммари вердикта (ответ первым абзацем по существу).
- Дописать в архив переписки: сообщение Саши дословно + выполнено (какой архитектор, куда легло).
- Спросить: собирать ли чистовик по правкам — только по явному «да» (R3: вопрос/намёк ≠ действие).
