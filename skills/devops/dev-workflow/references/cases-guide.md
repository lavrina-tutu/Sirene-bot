# Триггеры кейсов

Закрытый список из десяти кейсов и точные имена — `canon.md`/GLOSSARY. Норма очереди и продолжения — Б55/`../SKILL.md`.

| Смысл поручения | Кейс |
|---|---|
| новый инструмент / USERTOOL | `DEV` |
| доработка существующего | `CHANGE` |
| установленная малая доработка без новых сущностей | `CHANGE-LIGHT` |
| баг, ошибка, «не работает», «почини» | `BUGFIX` → `BUG:diagnose` |
| малый баг после диагноза | `BUGFIX-LIGHT` |
| исследование без кода | `RESEARCH` |
| миграция | `MIGRATION` |
| снятие инструмента | `DECOMM` |
| создание / изменение скилла | `SKILL-DEV` / `SKILL-CHANGE` |

«В бэклог / идея» — triage, а не автостарт. Кейс не является меню технических решений; сужение до LIGHT возможно только после установленного объёма и штатного гейта. Фазы и роли берутся из recipe и YAML.
